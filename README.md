

# 🛒 E-Commerce Sales Analysis (SQL Project)

## 📌 Overview

This project performs SQL-based analysis on an e-commerce dataset to extract meaningful business insights.

## 🛠️ Tools Used

* MySQL
* SQL

## 📊 Dataset Features

* Product Name
* Category
* Price
* Rating
* Revenue
* Stock
* City

## 🔍 Analysis Performed

### ✅ Basic Analysis

* Total revenue calculation
* Top 5 products by revenue

### 🚀 Intermediate Analysis

* Best rated products
* Revenue by city
* Low stock products

### 🔥 Advanced Analysis

* Product ranking using window functions
* Revenue contribution percentage
* Category-wise insights

## ⚙️ How to Run

1. Create database in MySQL
2. Run SQL script
3. Update file path in LOAD DATA query
4. Execute queries

## 📈 Key Insights

* Identified top-performing products
* Analyzed revenue distribution across cities
* Found stock and discount patterns
